Privacy policy

Aaron Inbox Assistant is a personal application operated by its owner. This page describes its Gmail integration.

Data accessed and purpose

With the owner's Google OAuth consent, the application can access the connected account's email address, message identifiers, sender and recipient information, subjects, message text, timestamps, and labels. This information is used to summarize mail, identify actions and deadlines, and support owner-approved mailbox organization.

The current agent tools are read-only. The requested Gmail modification permission also permits labeling and archiving when those features are explicitly enabled. Google bundles additional operations into that permission; the installed agent does not expose tools to send mail, change account settings, or permanently delete messages.

Processing and sharing

Gmail data is retrieved from Google to the owner's Mac. Email content selected for an AI request is sent to OpenAI using the owner's configured account to generate the requested response. OpenAI's processing and retention are subject to the applicable account terms, privacy policy, and data controls. If the owner enables iMessage delivery, selected summaries are sent through Apple's messaging service to the configured recipient.

The application does not sell Gmail data or use it for advertising. It is not designed to transfer mail to other recipients. Email attachments are not downloaded by the current integration.

Storage and retention

Google OAuth credentials are managed locally by the Gmail command-line client using macOS Keychain. OpenClaw may retain email content and summaries in local conversation history and logs until the owner deletes them. Data processed by Google, OpenAI, Apple, or the website host is also subject to those providers' policies.

Choices and deletion

The owner can stop the application and revoke its access from Google Account connections. Revoking access stops future authorized Gmail requests but does not automatically delete existing local histories, provider-retained data, or previously delivered summaries. The owner can remove local OpenClaw histories and logs and use provider account controls to manage other retained data.

Website and contact

This informational website is hosted by GitHub Pages. It has no sign-in form, email database, analytics scripts, or Gmail credentials. GitHub may process ordinary hosting request information. Questions about this personal application can be raised with its operator through the project's issue tracker. Do not include email content, credentials, or other private information in a public issue.

Changes

This disclosure will be updated when the application's data handling changes.
